# Snqup (Working Name)

Snqup is a mobile app for digital business cards, QR-based connection exchange, event networking, and link-in-bio. It replaces paper cards with a modern, context-aware digital identity that can be shared in person or online.

The product name is still under discussion; see [`docs/00-context/naming.md`](docs/00-context/naming.md) for the current placeholder policy.


All engineering documentation — context, architecture, ADRs, contracts, handoffs, schema, and runbooks — lives in [`docs/`](docs/README.md).

Start there: **[docs/readme.md](docs/README.md)**


**Rule of thumb:** If the documentation and the code disagree, fix one of them in the same pull request.
